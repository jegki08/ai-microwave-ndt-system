# AI-Based Microwave Non-Destructive Testing System for Composite Materials Using Python Antenna Simulation

Please see the full documentation and implementation in [`microwave_ndt_prototype/`](microwave_ndt_prototype/).

## Quick Start
To launch the complete application on Windows:
1. Double click `RUN_PROJECT.bat` in this directory or in `microwave_ndt_prototype/`.
2. Or run from PowerShell:
   ```powershell
   cd microwave_ndt_prototype
   .\.venv\Scripts\Activate.ps1
   python test_system.py
   streamlit run app.py
   ```

For detailed architecture, mathematical equations, actual model evaluation metrics, and physics assumptions, please refer to:
[microwave_ndt_prototype/README.md](microwave_ndt_prototype/README.md)
